INSTRUCCIONES PARA AGREGAR FOTOS DE DESARROLLADORES
=====================================================

Para agregar las fotografías de los 4 integrantes del equipo de desarrollo:

1. Coloca las imágenes en esta carpeta con los siguientes nombres:
   - desarrollador1.jpg (o desarrollador1.png)
   - desarrollador2.jpg (o desarrollador2.png)
   - desarrollador3.jpg (o desarrollador3.png)
   - desarrollador4.jpg (o desarrollador4.png)

2. Formatos soportados:
   - JPG / JPEG
   - PNG

3. Tamaño recomendado:
   - Imágenes cuadradas (1:1) funcionan mejor
   - Tamaño mínimo: 200x200 píxeles
   - Tamaño recomendado: 400x400 píxeles o más

4. Si no se coloca una imagen, se mostrará un icono por defecto.

5. Las imágenes se mostrarán automáticamente en forma circular en la página de desarrolladores.

NOTA: Si usas formato PNG, cambia la extensión en el código de .jpg a .png
o agrega soporte para ambos formatos en la vista developers.blade.php
